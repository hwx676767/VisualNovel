## 二、BGM（11 条，循环）

**放到：** `audio/bgm/{id}.mp3`（也认 `.ogg` / `.wav`）  
**总要求：** 60–90 秒可无缝循环 · **无歌词** · 立体声 · 峰值约 -3 dB · 199X 废土公路电影感（磁带/收音机，不是现代 EDM）

| 文件名 | 类型（找什么） | 解释（听感 / 怎么用） | 出现 |
|---|---|---|---|
| `audio/bgm/campsite.mp3` | **木吉他氛围 / Folk Ambient** | 篝火夜：柔和木吉他或轻拨弦，可加极轻蝉鸣/木柴底噪。暖、安静，像毕业前最后一晚。**不要**热闹流行、鼓点、合唱。 | 序章营地；路边过夜 |
| `audio/bgm/highway.mp3` | **公路电影 / Post-Rock Lite** | 废土公路主旋律：空旷合成垫音或慢速吉他，节奏可极轻（像轮胎碾过）。带一点往前走的希望，但路很空。**不要**摇滚高潮、说唱、赛博朋克。 | 公路主线；结局过渡 |
| `audio/bgm/tension.mp3` | **低压悬疑 / Dark Ambient Drone** | 加油站对峙：低频嗡鸣、慢脉冲，几乎无旋律。随时会出事的压迫感。**不要**跳跃惊吓音、快鼓、恐怖游戏尖叫垫。 | 第一章加油站 |
| `audio/bgm/hospital.mp3` | **冷钢琴 / Sparse Ambient** | 废弃医院：稀疏钢琴或冷色合成垫，音符间距大，像空走廊荧光灯。发冷、感染感。**不要**管弦史诗、恐怖追逃 BGM。 | 第一章医院 |
| `audio/bgm/tower.mp3` | **电波工业 / Radio Industrial** | 靠近广播塔：金属共鸣、短波电流、轻微失真谐波，有攀升感。**不要**重金属、舞曲 drop。 | 第二章末、第三章 |
| `audio/bgm/rooftop.mp3` | **极简风噪 / Wind Ambient** | 塔顶夜谈：比 tower 更空，几乎只有夜风 + 远处极弱电流。给对话留空间。**不要**完整主旋律抢戏。 | 第三章屋顶 |
| `audio/bgm/ending_hidden.mp3` | **轻喜剧 / Quirky Lounge** | 隐藏结局穿帮：突然轻松、略滑稽（轻爵士/复古 lounge/卡通感均可）。出戏、打破第四墙。**不要**史诗片尾、沉重悲剧。 | 隐藏结局 |
| `audio/bgm/ending_bad.mp3` | **压抑室内乐 / Melancholy Strings** | 坏结局墓碑：短句式、压抑弦乐或钢琴，像说不完的丧。**不要**恐怖尖叫、重金属、过度煽情合唱。 | 坏结局 |
| `audio/bgm/ending_normal.mp3` | **都市淡薄 / Lo-fi City** | 普通结局公寓：日常、淡薄、有点空的城市底噪或轻 lo-fi。像「还活着但牵绊变薄」。**不要**热血或甜蜜恋爱曲。 | 普通结局 |
| `audio/bgm/ending_good.mp3` | **温暖重逢 / Soft Acoustic** | 好结局十年后篝火：暖吉他或轻弦乐，怀旧但不甜腻。少年与成年叠在一起。**不要**偶像歌、过度欢快。 | 好结局 |
| `audio/bgm/ending_true.mp3` | **电影片尾 / Cinematic Clean** | 真结局谢幕：比 good 更干净、更收束，电影感钢琴/弦乐，可带轻微磁带质感。**不要**大合唱高潮、流行副歌。 | 真结局 |

**优先补：** `highway` → `campsite` → `tension` → `hospital` → `tower`

**找素材时可用英文关键词（每条对应）：**

| id | 搜索关键词示例 |
|---|---|
| `campsite` | acoustic campfire ambient, soft folk guitar loop, night campfire music no lyrics |
| `highway` | wasteland road trip ambient, desert highway post rock soft, empty road cinematic |
| `tension` | low drone tension ambient, quiet standoff underscore, dark pulse no drums |
| `hospital` | abandoned hospital ambient, sparse cold piano, empty corridor pad |
| `tower` | radio tower industrial ambient, shortwave static music, metallic drone climb |
| `rooftop` | night wind ambient sparse, rooftop quiet pad, almost silence wind loop |
| `ending_hidden` | quirky lounge comedy underscore, meta breaking fourth wall light music |
| `ending_bad` | melancholic short piano strings, graveyard quiet sadness, no horror jump |
| `ending_normal` | lonely city apartment lo-fi, thin daily life ambient |
| `ending_good` | warm reunion acoustic, soft nostalgic campfire reunion |
| `ending_true` | clean cinematic ending theme, quiet film credits piano |

## 三、SFX（6 条，一次性，不循环）

**放到：** `audio/sfx/{id}.mp3`  
**总要求：** 写实拟音优先 · 无音乐旋律 · 可单声道 · 枪/玻璃可比 BGM 稍刺一点

| 文件名 | 类型（找什么） | 解释（听感 / 怎么用） | 时长 | 出现 |
|---|---|---|---|---|
| `audio/sfx/engine.mp3` | **柴油房车引擎** | 老旧 RV / 柴油厢车启动或轰出去，低沉、有点破。**不是**跑车、摩托车、电动车。可含短促换挡感。 | 2–4 秒 | 序章出发；逃出后 |
| `audio/sfx/radio_static.mp3` | **AM/短波电流噪声** | 收音机沙沙声；中间可夹 **极短、听不清** 的人声碎片。像信号没锁稳。**不要**完整歌词或清晰播报。 | 2–5 秒 | 信号相关多处 |
| `audio/sfx/glass_crunch.mp3` | **踩碎玻璃拟音** | 脚下踩到碎玻璃：脆、短、地面感。加油站/废墟。**不要**窗户整片砸碎的长爆炸声。 | 0.5–1.5 秒 | 加油站 / 药店 |
| `audio/sfx/gunshot.mp3` | **单发手枪短响** | 一声近距枪响，短促。耳鸣留给 `heartbeat`。**不要**长尾爆炸、连发扫射、火箭弹。 | 0.3–1 秒 | 第一章中枪 |
| `audio/sfx/heartbeat.mp3` | **主观耳鸣 + 闷心跳** | 中枪/感染压迫：闷闷心跳 + 高频耳鸣，略失真。像「听自己身体」。**不要**恐怖鬼叫、完整音乐。 | 3–6 秒 | 中枪后 / 压迫感 |
| `audio/sfx/camera_shutter.mp3` | **机械胶片快门** | 老相机「咔嚓」：机械感、偏干。真结局仙对着你拍。**不要**手机电子快门音效、连拍。 | 0.3–0.8 秒 | 真结局 |

**优先补：** `gunshot` → `engine` → `radio_static` → `heartbeat`

**找素材时可用英文关键词：**

| id | 搜索关键词示例 |
|---|---|
| `engine` | diesel van start, old RV engine rev, box truck ignition |
| `radio_static` | AM radio static shortwave, tuning static with voice fragments |
| `glass_crunch` | footsteps on broken glass, glass crunch underfoot |
| `gunshot` | single pistol shot dry, short gunshot no explosion tail |
| `heartbeat` | tinnitus heartbeat POV, muffled heart ear ringing |
| `camera_shutter` | mechanical film camera shutter click, vintage SLR shutter |

## 四、怎么自检

1. 背景：放进 `backgrounds/` 后刷新，对应场景应盖住灰字占位。  
2. 音频：SETTINGS → Audio library，看 **FOUND / MISSING**。  
3. 文件名必须与上表 **id 完全一致**（小写 + 下划线，无空格无中文）。
