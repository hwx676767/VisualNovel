## 有限自由 · 说话 / 打断（已接入）

| 规则 | 实现 |
|---|---|
| 系统给的说话机会免费 | 剧情 `interactive` 不扣打断 |
| 自己抢话消耗打断 | 脚本推进等待时点 **Interrupt** |
| A 段每章 5 次 | `interruptsMaxA = 5`，进章重置 |
| B 段 2 次 | 场景 `segment: "B"` 时自动改为 2 |
| UI 一个数字 | 右上角 + 对话框 `Interrupt ×N` |

尽量不要做成「必须打断才能过」。

## 标准章结构（目标）

- **A**：A1 探索 → A2 消耗遭遇 → A3 决战（本章最重要的一句话）
- **B**：B1 闲聊 → B2 和闲看照片 → B3 各聊 / 接任务 → B4 陪伴模式可跳过

失败也往前走，不做「读档重试」结构；抗生素类失败导向坏结局。
