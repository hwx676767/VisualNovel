# Visual-novel — 视觉小说引擎原型

Vanilla HTML/CSS/JS 实现的 VN UI 壳，含打字机对话、历史记录、玩家输入区。

## 运行

直接用浏览器打开 `index.html`，或使用本地静态服务器。

## 结构

```
index.html    # 页面结构
main.js       # 游戏状态与交互
style.css     # 16:9 布局样式
data/         # 角色配置
characters/   # 立绘（占位）
backgrounds/  # 背景（占位）
```
