# 音频需求文档

把成品文件放进本文件夹后，**不用改剧情 JSON、不用改代码**。引擎会按文件名自动读取并播放。设置页 SETTINGS 会列出每条是 **FOUND** 还是 **MISSING**。

当前没有文件时，画面上方会短暂显示 `♪` 占位提示，游戏照常能玩。

---

## 1. 放到哪里

```
audio/
  bgm/     ← 循环背景音乐，文件名 = id
  sfx/     ← 一次性音效，文件名 = id
```

正确例子：

- `audio/bgm/highway.mp3`
- `audio/sfx/gunshot.mp3`

错误例子（引擎找不到）：

- `audio/highway.mp3`（放错层）
- `audio/bgm/Highway.mp3`（大小写不对）
- `audio/bgm/公路.mp3`（必须用英文 id）
- `audio/bgm/highway theme.mp3`（不能有空格）

---

## 2. 命名规则

| 规则 | 说明 |
|---|---|
| 名字 = id | 必须和下表 **id** 完全一致 |
| 小写 + 下划线 | `ending_true` 可以，`EndingTrue` 不行 |
| 不要空格、中文、括号 | `radio_static` 可以，`radio static (2)` 不行 |
| 扩展名 | 优先 `.mp3`，也认 `.ogg`、`.wav` |
| 查找顺序 | 同名时：`.mp3` → `.ogg` → `.wav` |

BGM 放 `audio/bgm/`，SFX 放 `audio/sfx/`，不要混放。

---

## 3. 必须交付（游戏已经接线）

共 **11 条 BGM + 6 条 SFX**。先做这些就能覆盖整局。

### BGM（循环，建议 60–90 秒，首尾能无缝接）

| 文件名 | 情绪 / 画面 | 出现位置 |
|---|---|---|
| `audio/bgm/campsite.mp3` | 毕业露营夜。篝火、蝉、有点暖的 90 年代木吉他。安静，不要热闹流行歌。 | 序章营地；第二章路边过夜 |
| `audio/bgm/highway.mp3` | 废土公路公路电影。尘土、空旷、RV 往前开。带一点希望，但路很空。 | 序章离开营地；第一～三章公路；结局过渡 |
| `audio/bgm/tension.mp3` | 低压对峙。低频、慢、随时会出事。不要鼓点太满。 | 第一章加油站对峙 |
| `audio/bgm/hospital.mp3` | 废弃医院。荧光灯、空走廊、感染后的发冷。稀疏钢琴或合成垫音。 | 第一章医院 |
| `audio/bgm/tower.mp3` | 靠近广播塔。电波、金属、攀升感。 | 第二章末接近塔；第三章塔 |
| `audio/bgm/rooftop.mp3` | 塔顶夜风。几乎只有风和远处电流，比 tower 更空。 | 第三章屋顶 |
| `audio/bgm/ending_hidden.mp3` | 隐藏结局。绿幕穿帮、突然轻松、带着点出戏的滑稽。可以轻快，不要史诗。 | Hidden Ending |
| `audio/bgm/ending_bad.mp3` | 坏结局。仙的墓、抗生素用尽。压抑、短句式旋律，不要恐怖尖叫。 | Bad Ending |
| `audio/bgm/ending_normal.mp3` | 普通结局。都市公寓、淡薄的牵绊。日常、有一点空。 | Normal Ending |
| `audio/bgm/ending_good.mp3` | 好结局。十年后篝火重逢。暖，但不甜腻。少年和成年叠在一起。 | Good Ending |
| `audio/bgm/ending_true.mp3` | 真结局 / 片尾。电影感、相机面对屏幕。可以比 good 更干净、更收。 | True Ending |

### SFX（一次性，不要循环）

| 文件名 | 内容 | 出现位置 | 建议时长 |
|---|---|---|---|
| `audio/sfx/engine.mp3` | RV 发动机启动 / 轰出去。柴油房车，不是跑车。 | 序章出发；第一章逃出后加速 | 2–4 秒 |
| `audio/sfx/radio_static.mp3` | 收音机电流噪音，中间可以有很短的、听不清的人声碎片。 | 序章公路；第一二章信号；第三章塔顶 | 2–5 秒 |
| `audio/sfx/glass_crunch.mp3` | 脚下踩碎玻璃。加油站 / 空城。 | 第一章加油站；第二章空镇 | 0.5–1.5 秒 |
| `audio/sfx/gunshot.mp3` | 一声枪。短。不要做成长尾爆炸；耳鸣用 heartbeat 接。 | 第一章仙中枪 | 0.3–1 秒 |
| `audio/sfx/heartbeat.mp3` | 耳鸣 + 闷心跳。中枪后、感染压迫感。 | 第一章中枪后 / 医院；第二章 | 3–6 秒 |
| `audio/sfx/camera_shutter.mp3` | 老相机快门。真结局仙对着你按快门。 | True Ending | 0.3–0.8 秒 |

## 4. 技术规格

| 项 | 要求 |
|---|---|
| 格式 | 优先 MP3（128–192 kbps 即可，不必无损） |
| 声道 | 立体声 BGM；SFX 单声道或立体声都可以 |
| 响度 | 峰值大约 -3 dB。BGM 要比对白安静一档，SFX 枪/玻璃可以更刺一点 |
| BGM 循环 | 首尾各留约 0.5–1 秒淡入淡出，接上时不要爆音或硬切 |
| 采样率 | 44.1 kHz |
| 人声 | **不要歌词**（游戏对白是英语口语，音乐会抢） |

时代感：**199X 废土公路电影**，磁带、收音机、夜风，不是现代 EDM。

---

## 5. 你放进去之后会发生什么

1. 把文件按上表命名丢进 `audio/bgm/` 或 `audio/sfx/`。
2. 刷新游戏（`npm start` 后打开 http://localhost:8765）。
3. 进入对应场景会自动播。
4. 点 SETTINGS → Audio library：绿字 **FOUND** 表示读到了，灰字 **MISSING** 表示还缺。
5. 有文件时画面会短暂显示 `♪ Now playing · …`；还没有文件时显示原来的占位 `♪ BGM · …`。

不需要告诉我改 JSON：只要文件名对，我就按 id 读。
