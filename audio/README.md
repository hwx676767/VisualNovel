# 音频素材目录

将最终音频放在这个 `audio/` 目录中，推荐使用 `.ogg`（网页体积更小）或 `.mp3`。

- `bgm_tension_loop.ogg`：持续紧张、搜索和对峙。
- `bgm_escape_loop.ogg`：逃离、驾车救援。
- `sfx_gunshot_01.ogg`：单次枪响。
- `sfx_alarm_01.ogg`：警报或突发危险。
- `sfx_car_engine_01.ogg`：房车发动、急加速。
- `sfx_radio_static_01.ogg`：收音机杂讯、电波。
- `sfx_heartbeat_01.ogg`：伤势和压迫感。

当前游戏会在对应剧情显示 `♪ 音效提示` 占位文字；素材就位后，可将同名文件接入播放逻辑，无需改动剧情数据中的提示。
